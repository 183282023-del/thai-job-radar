# 泰语工作雷达

面向泰语专业求职者的每日岗位聚合页面。页面自动展示月薪下限不低于
8,000 元的泰语相关岗位，优先排列西安、昆明机会，并明确标注在线投递路径。

## 在线更新

GitHub Actions 每天北京时间 08:00 运行：

1. 检索公开招聘页面。
2. 按薪资和泰语相关条件筛选。
3. 更新 `outputs/data/jobs.json`。
4. 重新发布 GitHub Pages。

公开网站只包含 `index.html`、样式、脚本和岗位 JSON，不包含抓取脚本或
本地服务代码。

## 本地运行

```bash
cd outputs
python3 server.py
```

然后访问 <http://127.0.0.1:8765>。

本地定时任务只在服务运行时执行；在线版本由 GitHub Actions 执行，不依赖
个人电脑开机。
