# 泰语工作雷达

一个零第三方依赖的本地网页应用：每天 08:00（Asia/Shanghai）检索公开招聘页面，筛选月薪下限不低于 8,000 元的泰语岗位，优先展示西安和昆明的机会，并标出投递路径。

## 启动

在 macOS 上可以直接双击 `启动网页.command`。它会启动本地服务并打开网页；使用期间请保留终端窗口。

也可以在本目录执行：

```bash
python3 server.py
```

然后打开 <http://127.0.0.1:8765>。

服务需要保持运行，才能执行每天 08:00 的自动检索。只双击 `index.html` 也能查看 2026-10-24 抓取的离线样例数据，但“立即检索”按钮不会联网。

## 筛选规则

- 职位标题必须包含“泰语”。
- 岗位标注的月薪下限必须不低于 8,000 元。
- 西安、昆明置顶。
- 最近 30 天更新或当前公开检索页仍无日期标识的结果会标为“待平台确认”。
- 只有招聘平台明确提供截止时间时，页面才应显示具体截止日。

## 数据层

`scraper.py` 使用 Python 标准库访问职友集移动端公开检索页。该站聚合了多平台职位，因此卡片中的具体招聘平台需要以职位详情页为准。每次成功抓取会保存到 `data/state.json`；某一来源临时限流时，服务继续展示上次有效数据。

招聘网站的页面结构与访问策略会变化。如果公开页面要求人工验证，后台会记录失败并保留缓存，不会绕过验证码或模拟登录。

## 文件

- `index.html`：页面结构与交互入口
- `styles.css`：完整响应式样式
- `app.js`：筛选、排序、收藏、导出和投递说明弹窗
- `seed.js`：首次打开时的离线样例数据
- `server.py`：API 与每日 08:00 定时任务
- `scraper.py`：公开检索页抓取与结构化
