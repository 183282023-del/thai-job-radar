# 编制岗雷达

面向泰语专业、亚非语言文学专业本科及以上学历用户的公务员、事业单位和参公岗位聚合页面。

## 当前收录规则

- 公务员岗位来自 2027 年国家公务员考试职位表的公开查询镜像。
- 招聘类型限定为公务员、事业单位、参公。
- 专业名称必须包含“泰语”；或包含不限定非泰语方向的“亚非语言文学”。
- 学历必须允许本科报考。
- 昆明、西安岗位优先排序。
- 只把仍在报名截止时间内的职位展示为可报岗位。

## 数据校验

职位表镜像用于检索，正式报名、职位条件与资格审查结果以国家公务员局和各地人社部门公告为准。页面同时监测云南、昆明和西安事业单位与地方公务员渠道。

## 本地预览

```bash
python3 -m http.server 8766
```

然后打开 <http://127.0.0.1:8766>。

在线版通过 GitHub Actions 每天北京时间 08:00 更新 `data.js` 并重新部署。
